# Беззвучный голос · Үнсіз дауыс

**Команда NYX · VentureHack 2026 · Трек 1: MedTech и здоровье человека**

Чтение по губам для людей, которые потеряли голос: после трахеостомии в реанимации, удаления гортани или инсульта. Пациент беззвучно произносит фразу, система распознаёт её через обычную веб-камеру, произносит вслух, а срочные просьбы сразу передаёт медсестре на телефон. Работает на русском и казахском, видео обрабатывается на устройстве и никуда не отправляется.

- **Обзор проекта:** https://flokko0-0.github.io/silent-voice/
- **Прототип в браузере:** https://flokko0-0.github.io/silent-voice/app.html

## Что умеет прототип

| Возможность | Как работает |
|---|---|
| Чтение по губам | MediaPipe Face Landmarker (478 точек лица) + сравнение с образцами методом DTW; на ноутбуке с сервером — предобученная нейросеть Auto-AVSR |
| Калибровка под человека | Каждая фраза произносится беззвучно 3–5 раз; поэтому подходит любой язык |
| Жесты без калибровки | Большой палец вверх/вниз — «Да»/«Нет», открытая ладонь — «Позовите врача», кулак — «Мне больно» |
| Подтверждение | Система переспрашивает («Хочу пить?»), пациент подтверждает жестом; ошибка не превращается в ложный вызов, а подтверждённая фраза становится новым образцом |
| Пост медсестры | Срочная фраза приходит на телефон со звуком и вибрацией; ответ «Иду» возвращается пациенту |
| Проверка точности | Кнопка в интерфейсе: каждая запись распознаётся по остальным (leave-one-out) |

## Точность

Замер на реальных записях: 35 записей, 7 фраз, один человек, встроенная камера ноутбука, leave-one-out.

| Способ | Точность |
|---|---|
| Точки губ MediaPipe + DTW | 71% |
| Нейросеть Auto-AVSR, последний слой энкодера | 69% |
| **Нейросеть Auto-AVSR, визуальный фронтенд + центрирование** | **91%** |
| То же, правильная фраза среди трёх вариантов | 97–100% |

Почему ранний слой лучше: модель обучена на английском видео, и глубокие слои кодируют английские слова. Визуальный фронтенд (3D-свёртка + ResNet) описывает форму и движение губ без привязки к языку. Вычитание среднего по калибровке убирает то, что общее у всех записей (лицо, освещение, губы в покое). Эксперименты воспроизводятся скриптами `tools/tune.mjs` и `ml/tune_neural.py`.

Это прототип: на пациентах система не испытывалась и не является медицинским изделием.

## Запуск

### Онлайн (без установки)

Откройте [app.html](https://flokko0-0.github.io/silent-voice/app.html) в Chrome или Edge, разрешите камеру, откалибруйте 2–3 фразы на вкладке «Калибровка». Пост медсестры в онлайн-версии открывается ссылкой на вкладке «Разговор» и получает сигналы во вкладке того же браузера. Нейросеть в онлайн-версии не используется, распознавание идёт по точкам губ.

### На ноутбуке (полная версия)

Нужен [Node.js](https://nodejs.org) 18+.

```bash
cd silent-voice
npm start
```

- экран пациента: http://localhost:5173/app.html
- пост медсестры: адрес вида `http://192.168.x.x:5173/nurse.html` печатается в консоли; телефон должен быть в той же сети Wi-Fi

### Нейросеть (необязательно)

Нужен Python 3.12. Код Auto-AVSR и веса модели в репозиторий не входят (большой размер, сторонняя лицензия):

```bash
cd silent-voice/ml
python -m venv .venv
.venv/Scripts/pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
.venv/Scripts/pip install -r requirements.txt

# код модели (Apache 2.0)
curl -L -o auto_avsr.zip https://github.com/mpc001/auto_avsr/archive/refs/heads/main.zip
unzip auto_avsr.zip

# веса визуальной модели Auto-AVSR (≈1 ГБ)
curl -L -o pytorch_model.pt https://huggingface.co/aaahmet/silent-lip-reader-model/resolve/main/pytorch_model.pt

.venv/Scripts/python embed_server.py
```

Сервер слушает `http://localhost:5174`; страница подключается к нему сама, в шапке появится «Распознавание: нейросеть». Веса загружаются в безопасном режиме (`torch.load(..., weights_only=True)`).

## Как устроено

```
камера ─► MediaPipe Face Landmarker ─► признаки губ (геометрия, blendshapes, контур)
   │                                        │
   │                                        ├─► начало/конец фразы по движению губ
   │                                        └─► DTW-сравнение с образцами (recognizer.js)
   │
   └─► выравнивание лица по 4 точкам, вырез рта 96×96 (mouth-crop.js)
                                            └─► Auto-AVSR фронтенд ─► DTW по косинусу (ml/embed_server.py)

MediaPipe Gesture Recognizer ─► жесты

фраза ─► подтверждение ─► синтез речи + тревога ─► server.mjs ─► пост медсестры (nurse.html)
```

| Файл | Назначение |
|---|---|
| `index.html`, `landing-data.js` | обзор проекта; анимация и графики построены по реальным записям |
| `app.html`, `app.js`, `style.css` | экран пациента: камера, калибровка, распознавание, жесты, тревога |
| `features.js` | признаки губ из точек MediaPipe |
| `recognizer.js` | распознавание по образцам (DTW) и проверка точности |
| `mouth-crop.js` | вырез области рта так же, как в Auto-AVSR |
| `nurse.html` | пост медсестры для телефона |
| `server.mjs` | статический сервер и пересылка сообщений (Server-Sent Events), без зависимостей |
| `ml/embed_server.py` | локальный сервер нейросети |
| `ml/tune_neural.py`, `tools/*.mjs` | эксперименты по точности и генерация данных для обзора |
| `vendor/` | MediaPipe Tasks Vision и модели (Apache 2.0), чтобы демо работало без интернета |
